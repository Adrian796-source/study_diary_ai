# Plan: 002-Objetivo Semanal de Estudio

## Enfoque Técnico
- Utilizar `localStorage` para persistir el objetivo semanal de minutos (ej. `diario_estudio_objetivo_minutos`).
- Calcular los minutos estudiados en la semana actual filtrando las sesiones registradas cuya fecha esté comprendida entre el lunes de la semana actual y el domingo actual.
- Actualizar la interfaz (HTML y CSS) para mostrar un panel/widget con el objetivo, los minutos acumulados y una barra de progreso o porcentaje, además de un control para editar el objetivo semanal.

## Fases de Implementación
1. **Tarea 1 (T1)**: Añadir lógica de almacenamiento y cálculo del progreso semanal en JavaScript (`app.js`).
2. **Tarea 2 (T2)**: Actualizar la interfaz HTML (`index.html`) y estilos (`styles.css`) para mostrar el widget del objetivo semanal y el botón/input para editarlo.
3. **Tarea 3 (T3)**: Añadir tests o validaciones y verificar que todo funciona correctamente.
